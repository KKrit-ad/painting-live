# Atelier เหมียว 🎨🐱

ฉากไลฟ์ TikTok แนวตั้ง 9:16 ที่มีแมวจิตรกร "ครูพู่กัน" วาดภาพคนดูสดๆ ตามคอมเมนต์และของขวัญที่ส่งมา ยิ่งของขวัญใหญ่ ภาพยิ่งอลังการ

ทั้งหมดอยู่ในไฟล์เดียว `index.html` ไม่ต้องติดตั้งหรือ build อะไร

## วิธีเปิด
เปิด `index.html` ในเบราว์เซอร์ได้เลย ด้านขวามีแผงจำลองไว้กดส่งคอมเมนต์ ของขวัญ และหัวใจ เพื่อดูว่าครูพู่กันวาดยังไง

## ระดับของขวัญ
| ส่งมา | ภาพที่ได้ |
|---|---|
| คอมเมนต์ฟรี | สเก็ตช์ดินสอ (จำกัดภาพฟรีต่อคนได้) |
| 1–9 เหรียญ 🌹 | สีน้ำ กรอบไม้ แทรกคิว |
| 10–99 เหรียญ 🍩 | สีน้ำมัน กรอบทอง |
| 100–999 เหรียญ 🎩 | เลือกสไตล์: อนิเมะ / ไซเบอร์พังก์ / ไทยโบราณ / ป๊อปอาร์ต |
| 1,000+ เหรียญ 🌌 | มาสเตอร์พีซ ยึดทั้งจอ + Hall of Fame |

## ฟีเจอร์
- **การวาด:** วาดภาพด้วย Canvas แบบหยาบไปละเอียด ดูดสีจากรูปโปรไฟล์ทีละฝีแปรง ไม่ใช้ AI
- **ช่วงถ่ายรูป:** "📸 แคปเลย!" นับ 3 2 1 พร้อมแถบชื่อคนดูและชื่อช่องในภาพ
- **ครูพู่กัน:** แมวอนิเมะที่เปลี่ยนสีหน้าตามเหตุการณ์ มีเหตุการณ์สุ่มให้ฮา (จาม วาดเพี้ยนแบบปิกัสโซ่ หลับรอคนปลุก)
- **เกมทายว่าครูวาดใคร:** คนแรกที่ทายถูกได้ภาพสีน้ำมันฟรี
- **ลูกเล่นในไลฟ์:** พลังแปรงจากหัวใจ (โหมดเทพวาดเร็ว x2) และหน้าต่างที่เปลี่ยนตามความคึกของไลฟ์
- **เพลง lofi:** สร้างเสียงสดในเบราว์เซอร์ ดังขึ้นตามความคึกของไลฟ์
- **แผงแอดมิน:** ข้ามภาพ (S) พักคิว (P) เริ่มเกมทาย (G) ลบ / แบนคนในคิว ตั้งเวลากันสแปมภาพฟรี

## ต่อกับ TikTok
หน้าเว็บเปิดฟังก์ชันไว้ให้ส่งเหตุการณ์เข้ามา:

```js
window.atelier.comment(name, text)
window.atelier.gift(name, coins, giftName, emoji, style?) // style: anime | cyber | thai | pop
window.atelier.like(name, count)
```

ขั้นต่อไป:
1. รับเหตุการณ์จากไลฟ์ด้วย `tiktok-live-connector` (Node.js ไม่ใช่ API ทางการ) แล้วส่งเข้าหน้าเว็บผ่าน WebSocket
2. เปลี่ยนตัวการ์ตูนสุ่มเป็นรูปโปรไฟล์ TikTok จริง
3. ซ่อนแผงควบคุม แล้วใช้หน้าเว็บเป็น Browser Source ใน TikTok LIVE Studio หรือ OBS ซึ่งต้องไลฟ์จากคอม
